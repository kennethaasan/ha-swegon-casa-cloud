# Security policy

Please report security-sensitive findings privately through GitHub's security
advisory feature rather than a public issue.

Never include Swegon API keys, access or refresh tokens, unit identifiers, AWS
IoT connection details, MQTT topics, Home Assistant diagnostics, or household
information in a public report. Revoke or rotate any credential that may have
been disclosed.

This project does not collect vulnerability telemetry and cannot revoke vendor
credentials on a user's behalf.
